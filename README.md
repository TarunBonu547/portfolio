# Tarun Bonu — Developer Portfolio

A premium, editorial-style personal portfolio built with vanilla HTML, CSS, and JavaScript.

## Structure

```
portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── assets/
│   ├── images/
│   ├── projects/
│   ├── certificates/
│   └── resume/
└── README.md
```

## Getting Started

Open `index.html` in a browser. No build step or server is required.

## Tech Stack

- HTML5
- CSS3 (custom properties, grid, flexbox)
- Vanilla JavaScript

## Fonts

- **Inter** — headings and body text
- **Space Grotesk** — display typography
- **IBM Plex Mono** — technical labels and metadata
